News Aggregator CLI
Overview
A Python-based command-line application that fetches news using NewsAPI, stores data in SQLite, removes duplicates, and exports results to CSV and Excel files.

Features:
- Fetch news articles by keyword
- Store data in SQLite database
- Export data to CSV and Excel
- Deduplication of news articles
- Simple CLI interface

Technologies Used:
- Python
- NewsAPI
- SQLite3
- Pandas
- OpenPyXL
Run the Project
`bash
python main.py
 
 Output Files
- news.db
- news.csv
- news.xlsx
